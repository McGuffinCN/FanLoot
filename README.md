# Fantia 批量下载器

在 Fantia 作者页面添加一个下载面板，可以按日期、订阅方案、文件类型筛选后，批量下载作品里的图片、视频、音频和附件，并按你设定的规则自动命名。

界面和流程参考了 [PixivFanboxDownloader](https://github.com/xuejianxianzun/PixivFanboxDownloader)，并针对 Fantia 重新实现。

## 功能

- 一次抓取某位作者的全部投稿，也可以只抓取当前这一篇
- 按投稿日期范围筛选（按日本时间计算）
- 按订阅方案筛选，精确到作品里的每个内容区块
- 按文件类型筛选：图片、视频、音频、附件、封面、正文
- 可以按标题关键词包含或排除作品
- 自定义文件名和文件夹规则，并实时预览
- 支持多个文件同时下载、暂停、继续、停止和重试失败的文件
- 会记住已下载的文件，再次下载时可以跳过
- 可以复制筛选结果的全部下载链接

## 使用方法

1. 登录 Fantia，打开某位作者的主页、作品列表或任意作品页面。
2. 点击页面右下角的下载按钮，打开面板。
3. 在“抓取筛选”里设置日期范围、订阅方案和文件类型，然后点击“开始抓取”。
4. 在“文件名与下载”里设置命名规则，确认预览无误后，点击“开始下载”。

## 文件名规则

默认规则：

`Fantia/{user}/{date} {title} ({post_id})/{index}_{name}`

用 `/` 可以创建文件夹。规则里不写 `{ext}` 时，会自动补上扩展名。

| 变量 | 含义 | 变量 | 含义 |
|---|---|---|---|
| `{user}` | 作者名称 | `{date}` | 投稿日期 |
| `{title}` | 投稿标题 | `{post_id}` | 投稿 ID |
| `{index}` | 投稿内序号 | `{name}` | 原文件名 |
| `{plan}` | 订阅方案 | `{price}` | 方案月费 |
| `{type}` | 文件类型 | `{tags}` | 标签 |
| `{year}` `{month}` `{day}` | 年、月、日 | `{time}` | 投稿时间 |
| `{fanclub}` | 粉丝团名称 | `{fanclub_id}` | 粉丝团 ID |
| `{content_title}` | 内容区块标题 | `{content_id}` | 内容区块 ID |
| `{page}` | 区块内序号 | `{ext}` | 扩展名 |

`{date}` 的格式可以自定义，例如 `YYYY-MM-DD`、`YYYYMMDD`、`YYYY-MM-DD_HH-mm`。

## 推荐设置

建议使用 **Tampermonkey**，并在 Tampermonkey 的设置里调整以下选项（需要把“配置模式”切换为“高级”才能看到）：

- 想按文件夹保存：在“下载 BETA → 下载模式”中选择 **浏览器 API**。
- 视频、压缩包等文件下载失败时：在“下载 BETA → 白名单扩展名”中添加对应扩展名，或者填写 `/.*/`。
- 如果每个文件都弹出“另存为”窗口：请在浏览器设置里关闭“下载前询问每个文件的保存位置”。

## 注意事项

- 只能下载当前账号已经有权限查看的内容。未订阅或方案等级不够的内容会被跳过，并在面板中显示数量。
- 只能在线播放、没有下载按钮的视频无法下载。
- 下载链接有时效。抓取完很久才开始下载、出现大量失败时，请重新抓取。
- 作品很多时，建议把请求间隔设为 600 毫秒以上，以免请求过于频繁。
- 请尊重创作者的权益，下载的内容仅供个人使用，请勿转载或二次分发。
